# Indicaciones de coordinación — Guía pastoral - Biblia

Para cualquier IA, colaborador o agente que trabaje con el lanzamiento de la app Android **Guía pastoral - Biblia**:

- **Leer primero [docs/guia-pastoral/PUBLICACION_UPTODOWN.md](docs/guia-pastoral/PUBLICACION_UPTODOWN.md)**. Contiene la ficha pública de tres párrafos, el inventario de imágenes pendientes, contacto, decisiones, fechas, requisitos y el procedimiento de publicación.
- Revisar también la [actividad de seguimiento #67](https://github.com/cmiloarevalo-hash/Lago-1/issues/67) antes de marcar tareas completadas.
- **2026-11-09:** la página web de Wix ya existe; el destino elegido es **Uptodown**; la APK definitiva está pendiente de compilación, revisión y aprobación del autor; no existe todavía un enlace oficial de la ficha de descarga.
- **No enviar archivos a Uptodown, publicar ni actualizar la web de descarga sin autorización expresa del autor.** No confundir QA/candidata con release final.
- No modificar la APK estable QA5 ni fusionar cambios de código de publicación por cuenta propia. No publicar secretos, firmas privadas, contraseñas o información personal no aprobada.
- El repositorio es público. La web de Wix y Uptodown están destinados a lectores; GitHub es solamente para coordinación técnica.
- Cualquier cambio de estado relevante debe registrarse en la bitácora del documento canónico y en el Issue #67.

Estas instrucciones son de **coordinación documental**; no sustituyen las decisiones editoriales del autor.
